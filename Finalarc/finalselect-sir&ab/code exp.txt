 d) Defining Autoencoder Architecture

```python
class AutoEncoder(Model):
  def __init__(self, output_units, ldim=8):
    super().__init__()
    self.encoder = Sequential([
      Dense(64, activation='relu'),
      Dropout(0.1),
      Dense(32, activation='relu'),
      Dropout(0.1),
      Dense(16, activation='relu'),
      Dropout(0.1),
      Dense(ldim, activation='relu')
    ])
    self.decoder = Sequential([
      Dense(16, activation='relu'),
      Dropout(0.1),
      Dense(32, activation='relu'),
      Dropout(0.1),
      Dense(64, activation='relu'),
      Dropout(0.1),
      Dense(output_units, activation='sigmoid')
    ])

  def call(self, inputs):
    encoded = self.encoder(inputs)
    decoded = self.decoder(encoded)
    return decoded
```

 Meaning:
  Defines a custom Autoencoder class with encoder and decoder networks. Encoder reduces input to latent space; decoder reconstructs input.

 Importance + Logic:
  Autoencoder learns compressed representations. Reconstruction errors are used to detect anomalies.

 f) Thresholding and Anomaly Detection

```python
def find_threshold(model, x_train_scaled):
  reconstructions = model.predict(x_train_scaled)
  reconstruction_errors = tf.keras.losses.msle(reconstructions, x_train_scaled)
  threshold = np.mean(reconstruction_errors.numpy()) + np.std(reconstruction_errors.numpy())
  return threshold
```

 Meaning:
  Calculates reconstruction error threshold using training data.

 Importance + Logic:
  Threshold separates normal and anomalous patterns; errors above threshold are anomalies.

---

```python
def get_predictions(model, x_test_scaled, threshold):
  predictions = model.predict(x_test_scaled)
  errors = tf.keras.losses.msle(predictions, x_test_scaled)
  anomaly_mask = pd.Series(errors) > threshold
  preds = anomaly_mask.map(lambda x: 0.0 if x == True else 1.0)
  return preds
```

 Meaning:
  Predicts anomalies in test data based on threshold.

 Importance + Logic:
  Classifies each sample as normal (1) or anomaly (0) based on reconstruction error.


 Meaning:

 d) One-Hot Encoding

```python
def one_hot(word):
    v = torch.zeros(vocab_size)
    v[word_to_ix[word]] = 1
    return v
```

 Meaning:
  Converts a word into a one-hot vector of size `vocab_size`.

 Importance + Logic:
  One-hot vectors represent words numerically for input to the neural network.

---

```python

for ctx, tgt in data:
    ctx_vec = sum(one_hot(w) for w in ctx) / len(ctx)
    X.append(ctx_vec)
    Y.append(torch.tensor([word_to_ix[tgt]]))

X = torch.stack(X)
Y = torch.stack(Y).squeeze()
```

 Meaning:

 Converts target words to tensor indices (Y)

 Stacks them into tensors for training

 Importance + Logic:

 e) Define CBOW Model

```python
class CBOW(nn.Module):
    def __init__(self, vocab, dim=8):
        super().__init__()
        self.emb = nn.Linear(vocab, dim)
        self.out = nn.Linear(dim, vocab)

    def forward(self, x):
        return self.out(self.emb(x))
```

 Meaning:
  Defines a CBOW neural network with one hidden layer:

 `emb` reduces input dimension

 `out` predicts word probabilities

 Importance + Logic:
  The network learns embeddings of words in a low-dimensional space and predicts target word from context.
