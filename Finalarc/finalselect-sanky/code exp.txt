## CODE EXPLANATION (SPPU BE IT 2019 Pattern – Line-by-Line, 
Easy Language, Logic included under Importance)

---

### a) Import Required Libraries

```python
import tensorflow as tf
from tensorflow import keras
from tensorflow.keras import layers
import numpy as np
import matplotlib.pyplot as plt
```

**Meaning:**
Imports TensorFlow/Keras for deep learning, Numpy for 
numerical computations, and Matplotlib for visualization.

**Importance + Logic:**
These libraries are essential for building the Autoencoder, 
performing array operations, and visualizing input vs 
reconstructed images for anomaly detection.

---

### b) Load and Access the Dataset (MNIST)

```python
(x_train, _), (x_test, _) = keras.datasets.mnist.load_data()
```

**Meaning:**
Loads the MNIST dataset for training and testing. 
Labels are ignored for unsupervised anomaly detection.

**Importance + Logic:**
Autoencoder learns to reconstruct normal patterns; labels are not required. 
MNIST images provide a standard dataset for demonstration.

---

### c) Normalize and Reshape

```python
x_train = x_train.astype("float32") / 255.0
x_test = x_test.astype("float32") / 255.0
x_train = x_train.reshape((len(x_train), 28, 28, 1))
x_test = x_test.reshape((len(x_test), 28, 28, 1))
```

**Meaning:**
Normalizes pixel values to 0–1 and reshapes to 28×28×1 for CNN input.

**Importance + Logic:**
Normalization helps model converge faster. Reshaping is necessary for 
Conv2D layers which expect 3D input (height, width, channels).

---

### d) Build the Autoencoder Model

#### Encoder

```python
encoder = keras.Sequential([
    layers.Input(shape=(28, 28, 1)),
    layers.Conv2D(16, (3,3), activation='relu', padding='same'),
    layers.MaxPooling2D((2,2), padding='same'),
    layers.Conv2D(8, (3,3), activation='relu', padding='same'),
    layers.MaxPooling2D((2,2), padding='same')
])
```

**Meaning:**

* Input → Conv2D + ReLU → MaxPooling → Conv2D + ReLU → MaxPooling.
* Converts image into compressed latent representation.

**Importance + Logic:**
Encoder extracts important features and reduces dimensionality 
while preserving structure, capturing normal patterns in the data.

---

#### Decoder

```python
decoder = keras.Sequential([
    layers.Conv2D(8, (3,3), activation='relu', padding='same', input_shape=(7,7,8)),
    layers.UpSampling2D((2,2)),
    layers.Conv2D(16, (3,3), activation='relu', padding='same'),
    layers.UpSampling2D((2,2)),
    layers.Conv2D(1, (3,3), activation='sigmoid', padding='same')
])
```

**Meaning:**

* Upsamples latent features → Conv2D layers → reconstructs original image dimensions.
* Output layer uses sigmoid to produce pixel values between 0–1.

**Importance + Logic:**
Decoder reconstructs the input image from compressed features. 
Differences between input and reconstruction indicate anomalies.

---

#### Combine Encoder + Decoder

```python
autoencoder = keras.Sequential([encoder, decoder])
```

**Meaning:**
Stacks encoder and decoder into a single Autoencoder model.

**Importance + Logic:**
Autoencoder learns to reconstruct input images. Reconstruction error is used to detect anomalies.

---

### e) Compile the Model

```python
autoencoder.compile(optimizer='adam', loss='mse', metrics=['accuracy'])
```

**Meaning:**
Compiles Autoencoder with Adam optimizer, mean squared error loss, and accuracy metric.

**Importance + Logic:**
Adam optimizer efficiently updates weights. MSE measures difference 
between input and reconstruction, which is crucial for anomaly detection.

---

### f) Train the Model

```python
history = autoencoder.fit(x_train, x_train,
                          epochs=5,
                          batch_size=128,
                          validation_split=0.1,
                          verbose=1)
```

**Meaning:**
Trains the model to reconstruct input images from training set.

**Importance + Logic:**
Model learns normal patterns in data. Validation split ensures the model 
generalizes well and avoids overfitting.

---

### g) Evaluate and Visualize Reconstruction

```python
decoded_imgs = autoencoder.predict(x_test[:10])

plt.figure(figsize=(10, 4))
for i in range(10):
    # Original
    plt.subplot(2, 10, i + 1)
    plt.imshow(x_test[i].reshape(28, 28), cmap="gray")
    plt.axis("off")

    # Reconstructed
    plt.subplot(2, 10, i + 11)
    plt.imshow(decoded_imgs[i].reshape(28, 28), cmap="gray")
    plt.axis("off")

plt.suptitle("Top: Original Images | Bottom: Reconstructed (Autoencoder Output)")
plt.show()
```

**Meaning:**
Displays original images (top) and reconstructed images (bottom) for comparison.

**Importance + Logic:**
Visualizes reconstruction performance. Poor reconstruction indicates potential anomalies.

---

### h) Anomaly Detection

```python
reconstructions = autoencoder.predict(x_test)
mse = np.mean(np.power(x_test - reconstructions, 2), axis=(1,2,3))
threshold = np.mean(mse) + 2*np.std(mse)

print(f"Anomaly Detection Threshold: {threshold:.6f}")

# Example: Detect anomalies
anomalies = mse > threshold
print(f"Detected {np.sum(anomalies)} anomalies out of {len(x_test)} samples.")
```

**Meaning:**

* Computes MSE between input and reconstructed images.
* Sets threshold for anomaly detection.
* Flags images with reconstruction error above threshold as anomalies.

**Importance + Logic:**
High reconstruction error indicates the model cannot reconstruct the input 
well, implying anomaly. Thresholding provides a practical way to detect 
abnormal samples.

---

* Builds **Autoencoder** with encoder-decoder CNN architecture.
* Trains model to reconstruct normal input images.
* Computes reconstruction error and flags samples above threshold as 
anomalies.
* Visualizes reconstructed images for understanding model performance.


**Meaning:**
